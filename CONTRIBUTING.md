# Contributing Guidelines

Thank you for your interest in contributing to this repository! Follow these steps to add a new post:

1. **Create a New Markdown File**:
   - Navigate to the `posts/` directory.
   - Create a new `.md` file with a descriptive name for your post (e.g., `my-new-post.md`).

2. **Write Your Post**:
   - Use Markdown syntax to format your post.
   - Include a title, author name, and date at the top of the file.

3. **Style Your Post**:
   - Ensure your post follows the repository's style guidelines.
   - Use the `public/styles.css` file for consistent styling.

4. **Submit Your Changes**:
   - Commit your changes to a new branch.
   - Open a pull request for review.

We appreciate your contributions and look forward to your posts!
